# 0002. Анонимная идентичность установки

## Статус

Принято.

## Решение

При первом запуске мобильное приложение создаёт случайный UUID установки и независимый 256-битный секрет. Значения сохраняются только в защищённом хранилище платформы: Android Keystore или iOS Keychain. В интерфейсе и диагностике разрешено показывать только UUID; секрет нельзя логировать, копировать в обычную SQLite-базу или включать в резервную копию.

Идентификатор не вычисляется из IMEI, Android ID, рекламного идентификатора, имени устройства или других аппаратных и персональных данных. Он не является учётной записью и не позволяет автоматически объединять несколько устройств одного человека.

Повреждённый или неполный набор реквизитов заменяется целиком. UUID записывается последним и служит признаком завершённого создания пары UUID/секрет.

## Следующий серверный этап

При первой синхронизации сервер зарегистрирует UUID и сохранит только криптографический хэш секрета. После проверки владения установкой сервер сможет выдавать короткоживущую сессию. Это позволит изолировать заметки и задания без экрана входа, сохранив возможность добавить перенос данных между устройствами отдельным механизмом в будущем.
