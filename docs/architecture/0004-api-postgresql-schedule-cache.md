# ADR 0004: ASP.NET Core API и PostgreSQL-кэш расписания

## Статус

Принято.

## Контекст

Мобильный MVP умеет читать официальный JSON API КФУ напрямую, однако production-серверу нужны единые публичные маршруты, журнал публикаций каталога и рабочая копия расписания на случай временной недоступности источника. Непроверенный или пустой ответ КФУ не должен заменять ранее сохранённые данные.

## Решение

- ASP.NET Core API отдаёт каталог институтов, направлений, групп и преподавателей, расписание группы и точное расписание преподавателя, а также текущую и следующую пару.
- Официальный `https://cfuv.ru/wp-json/cfu/v1/sched/` остаётся первичным источником расписания.
- Каждый успешно разобранный документ сохраняется в PostgreSQL как `jsonb` в `schedule_source_documents`. При сетевой ошибке, ошибке формата или временной недоступности источника используется последняя проверенная копия.
- Обогащённый справочник преподавателей и специальностей публикуется атомарно в `reference_catalog_documents`; старый импорт не может заменить более новый. Каждая попытка публикации записывается в `reference_catalog_import_logs`.
- Большой справочник хранится единым версионированным JSON-документом, потому что это готовый immutable snapshot для мобильного клиента. Установки, заметки, задания, tombstones и реестр мутаций остаются нормализованными таблицами.
- Импортёр поддерживает `--publish-postgres` после полного обновления и `--seed-postgres` для загрузки уже проверенного встроенного справочника без повторного сетевого обхода.
- `/health/live` проверяет процесс, `/health/ready` — доступность PostgreSQL. EF Core-миграции применяются при старте только при явной настройке `Database__ApplyMigrationsOnStartup=true`.

## Ограничения

- PostgreSQL-кэш создаётся после первого успешного запроса конкретной группы или преподавателя; до этого недоступность КФУ корректно возвращает HTTP 503.
- Аудитории не дополняются вручную: API показывает только опубликованные КФУ значения.
- Установочная идентичность не переносит личные данные между разными устройствами.
