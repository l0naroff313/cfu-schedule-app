Официальный API — основной источник. Этот снимок используется только при недоступности сети; более новый локальный кэш не заменяется. Временные Excel-переопределения сняты. Карточки преподавателей сохранены, их расписания заменены официальными.

## Проверки обновления 1.0.7

- Независимая сверка сохранённых ответов API: все 592 группы, 15254 строки занятий и факультативы совпадают по полям, используемым приложением. ПИ-б-о-252: 33 исходные строки для обеих подгрупп; выбор первой подгруппы не изменён.
- Сохранены все 2357 прежних карточек преподавателей, включая ФИО, должность, дисциплины, специальности и ссылки; всего в новом каталоге 2444 карточки.
- Основной источник — `https://cfuv.ru/wp-json/cfu/v1/sched/`. Снимок в файле с историческим именем `cfu-manual-schedule.json` имеет `preferOfficialApi: true` и не перекрывает успешный ответ сайта.
- Ежедневное обновление — в 06:00 МСК (03:00 UTC), независимо от часового пояса устройства. При запуске выполняется фоновая загрузка после отображения локального расписания; при ошибке повтор через 15 минут, пока приложение активно. Закрытая PWA и остановленное ОС Android-приложение не гарантируют запуск ровно в 06:00.
- 103 теста общего мобильного ядра и 17 тестов импортёра: время обновления, приоритет официального API, удалённые занятия, сохранение более нового кэша, примечания с датой начала, полнота импорта, сохранение карточек преподавателей. Повреждённый JSON, отсутствие списка занятий и ответ для другой группы не затирают рабочую копию.
- Проверены холодный офлайн-запуск, восстановление кэша и личные записи в Chromium для корневого адреса и подпапки. Проверка на физическом iPhone не выполнялась; WebKit-тесты пропускаются из-за ограничений service worker в тестовом окружении.

## Изменённые компоненты

- Общее мобильное ядро: источник расписания, резервная копия, преобразование дат и планировщик обновления.
- Импортёр: режим `--official-schedule`, проверка полноты, обновление расписаний преподавателей без удаления их анкет.
- Общие JSON-данные, версии APK/PWA, тесты и README. Личные заметки и задания не изменялись.
