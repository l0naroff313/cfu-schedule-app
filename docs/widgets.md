# Виджет КФУ ЭлЖур

## Android

Нативный AppWidgetProvider включён в APK v1.0.8. Макет использует вертикальные веса 3:4: верхняя область занимает 3/7 высоты, список — 4/7. Для размеров 3×4, 3×5, 3×6, 4×3, 4×4, 4×5 и 4×6 применяются те же веса и шесть адаптивных строк; Android масштабирует их при других размерах.

Верхняя область имеет два горизонтальных блока: название занимает 2/3, справа время и кабинет занимают 1/3. Названия с ellipsize=marquee прокручиваются один раз. Прогресс-бар показывает долю текущей пары; на перемене он показывает долю интервала до следующей пары. В состоянии конца дня виджет меняет подпись на «завтра» и переносит список на ближайший следующий день.

ScheduleWidgetStateBuilder находится в общем мобильном ядре, поэтому состояние виджета и экраны приложения используют один формат урока, часовой пояс КФУ (UTC+03:00), кэш и идентификаторы заметок. MobileWidgetDataPublisher записывает сериализованное состояние в Android Preferences после изменения расписания или заметок. CfuScheduleWidgetProvider читает только эту локальную копию и не выполняет сетевые запросы.

## iOS

iOS Home Screen widgets реализуются через отдельный WidgetKit extension target. .NET MAUI-приложение уже содержит общий расчёт состояния, но добавление подписанной iOS-расширенной цели и проверка WidgetKit требуют macOS и Xcode. Поэтому в этой версии Android-виджет готов, а iOS-виджет остаётся отдельным этапом TestFlight-сборки.
