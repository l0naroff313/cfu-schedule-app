# Проверка и исправления 1.0.10

Дата проверки: 18 сентября 2026 года.

## Причина пустого расписания

Официальный `https://cfuv.ru/wp-json/cfu/v1/sched/index` во время проверки возвращал
пустой список нечётных недель, чётные недели только с 5 октября и текущую неделю
14 сентября. При этом `group?code=…` содержал занятия ПИ-б-о-252 и МАТ-б-о-261.
Прежняя проверка принимала такой календарь и сохраняла его: повторяющиеся занятия
не разворачивались на сентябрь, и интерфейс сообщал об отсутствии пар.

При повторной проверке перед публикацией КФУ уже восстановил обе чётности
(8 чётных и 8 нечётных недель). Регрессионные тесты сохраняют сценарий исходного
сбоя, а клиент автоматически возвращается к корректному официальному календарю.

## Исправления

- Общий для APK/PWA слой проверяет календарь до сохранения: обе чётности,
  корректные понедельники, отсутствие повторов/пересечений/пропусков и наличие
  указанной сервером текущей недели.
- Неполный ответ не заменяет проверенную копию. При повреждении старого кэша
  используются сохранённый календарь группы, валидный общий календарь или
  встроенный проверенный снимок. Произвольные даты не достраиваются.
- Новые занятия всё равно загружаются из официального API, а не подменяются
  старым Excel. О запасном календаре выводится предупреждение; время его
  сохранения не выдаётся за время успешного нового обновления.
- Каталог выбора группы больше не перезаписывает календарный кэш.
- Чётность интерфейса берётся из того же календаря, что и занятия. Дата вне
  загруженного диапазона отличается от дня без пар.
- Исправлены сохранение дедлайна из `datetime-local` с секундами, повторное
  планирование после изменения текста и отмена уже поставленных callbacks.
- PWA использует `ServiceWorkerRegistration.showNotification`, проверяет
  разрешение и готовность worker; нажатие уведомления открывает приложение.
- Android передаёт отдельный идентификатор для каждого уведомления задания.

Основные изменённые файлы: `CfuCalendarIntegrity.cs`, `CfuScheduleRepository.cs`,
`CfuScheduleDocuments.cs`, `ScheduleSession.cs`, `SchedulePageViewModel.cs`,
`TodayPageViewModel.cs`, `ProfileSetupViewModel.cs`, `WebAppState.cs`, `Home.razor`,
`browser-services.js`, `service-worker.published.js`,
`AndroidAssignmentReminderScheduler.cs`. Добавлены регрессионные проверки
в `CfuScheduleRepositoryTests.cs`, `offline.test.cjs`, `notifications.test.cjs`.
Версия клиента и README обновлены до 1.0.10.

## Ограничения и обновление

Это регрессионная проверка доступных сценариев, а не гарантия отсутствия любых
ошибок. Физический iPhone/Safari не проверен: два WebKit offline-теста явно
пропущены из-за ограничений активации service worker в тестовом окружении.
Запуск тестов Infrastructure сам по себе не подтверждает работу production PostgreSQL.
Закрытая PWA по-прежнему не получает локальные таймерные напоминания — для этого
нужен Web Push. Доступность календаря на стороне КФУ остаётся внешней зависимостью;
запасная копия имеет ограниченный учебным периодом диапазон.

PWA: открыть с интернетом, закрыть все окна приложения и открыть снова после
установки новой версии worker; затем нажать «Профиль → Обновить офлайн-данные».
Не очищать данные сайта: там хранятся личные заметки и задания.

APK: скачать 1.0.10 из GitHub Releases. Нынешние CI-сборки используют временный
ключ подписи; при конфликте подписи не удалять старое приложение без сохранения
личных данных. Для бесшовных обновлений нужен постоянный release-keystore.
