# Обновление расписания из Excel

## Что загружено сейчас

Текущий локальный слой расписания собран из `расписание.zip`, переданного оператором 7 сентября 2026 года. Обработано 10 таблиц, 62 группы и 2480 строк занятий. В частности, добавлено расписание группы `ПИ-б-о-252` для первой подгруппы.

Файл университета использует визуальную форму: в каждом блоке идут день недели, номер пары, предмет, преподаватель и аудитория; отдельные блоки описывают чётную и нечётную недели. Импорт сохраняет эту семантику, а не пытается превратить таблицу в плоский список без недельности.

## Как добавить или изменить расписание

```powershell
dotnet run --project src/UniversitySchedule.ScheduleImporter -- `
  --excel "C:\путь\к\новому-файлу.xlsx" `
  --academic-year 2026
```

Допустимы также ZIP-архив или каталог с несколькими `.xlsx`:

```powershell
dotnet run --project src/UniversitySchedule.ScheduleImporter -- `
  --excel "C:\путь\к\таблицам.zip" `
  --academic-year 2026
```

Импорт атомарно обновляет два результата:

- `src/UniversitySchedule.Mobile/Resources/Raw/cfu-manual-schedule.json` — приоритетные занятия групп для Android и PWA;
- `src/UniversitySchedule.Mobile/Resources/Raw/cfu-reference-catalog.json` — расписания преподавателей и календарь недель.

В приложении данные из Excel имеют приоритет только для перечисленных в файле групп. Остальные группы продолжают получать официальное расписание КФУ. Поэтому временный файл можно заменить следующим файлом без риска потерять актуальные данные сайта.

После импорта нужно пересобрать APK и PWA. Личные заметки и задания не изменяются: их идентификаторы привязаны к занятиям и сохраняются в локальном хранилище.
